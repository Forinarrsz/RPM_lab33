# Лабораторная работа №33: Обработка данных с использованием LINQ

## Описание
Приложение на C# (Windows Forms) для демонстрации работы с LINQ to Objects. Программа позволяет вводить данные о студентах, сохранять их в коллекции и выполнять фильтрацию, сортировку и поиск с помощью LINQ-запросов.

## Требования
- Visual Studio 2019 или новее
- .NET 6.0+ или .NET Framework 4.7.2+
- Подключенное пространство имен `System.Linq`

## Структура проекта
- `Student.cs` — класс модели данных
- `Form1.cs` — логика формы и обработчики событий
- `Form1.Designer.cs` — разметка элементов управления
- `Program.cs` — точка входа

## Запуск
1. Откройте файл `.sln` в Visual Studio.
2. Выполните `Build -> Rebuild Solution`.
3. Запустите проект клавишей `F5`.

## Использование
1. Заполните поля ввода (номер билета, ФИО, дата рождения, группа, 4 оценки).
2. Нажмите **Добавить студента** для сохранения данных в коллекцию `List<Student>`.
3. Используйте кнопки фильтрации для вывода результатов в `DataGridView`:
   - **Показать всех студентов** — отображает полную таблицу.
   - **Должники** — выводит студентов, имеющих хотя бы одну оценку 2.
   - **Младше 20 лет** — выводит студентов младше 20 лет, отсортированных по возрастанию.
   - **Показать группу** — поиск студентов по введенному названию группы.

## Реализованные LINQ-запросы

**Должники (наличие оценки 2)**
```csharp
var debtors = students
    .Where(s => s.Grades.Any(g => g == 2))
    .Select(s => new { ФИО = s.FullName, Группа = s.Group, Оценки = string.Join(", ", s.Grades) })
    .ToList();
```

**Младше 20 лет (с сортировкой)**
```csharp
var young = students
    .Where(s => s.Age < 20)
    .OrderBy(s => s.Age)
    .ThenBy(s => s.LastName)
    .Select(s => new { ФИО = s.FullName, Возраст = s.Age, Группа = s.Group })
    .ToList();
```

**Поиск по группе**
```csharp
var group = students
    .Where(s => s.Group.ToUpper() == txtSearchGroup.Text.Trim().ToUpper())
    .Select(s => new { Номер_билета = s.StudentId, ФИО = s.FullName })
    .ToList();
```

## Примечания
- Все поля ввода должны проверяться перед парсингом чисел (`int.TryParse`).
- Для корректной работы с DataGridView рекомендуется установить `dataGridView1.AutoGenerateColumns = false;` и настроить колонки вручную.
- При ошибках компиляции вида `не существует в текущем контексте` проверьте `Form1.Designer.cs` на наличие лишних подписок на события (например, `txtStudentId_Click`) и удалите их.
